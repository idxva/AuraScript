# About AuraScript

AuraScript is a prototype digital prescription tool for creating encrypted prescription handoffs between doctors and pharmacies. Doctors can set up a local profile, enter patient and medication details, and generate an OTP/QR code that pharmacists can use to retrieve the encrypted prescription payload from the companion Flask API.
